# Social Network Ads Purchase Prediction

## Project Overview
This project uses machine learning to predict whether a customer will purchase a product based on demographic data from social network advertisements.

## Dataset
The dataset contains customer demographic information collected from social network ads.

Features include:
- Gender
- Age
- Estimated Salary

Target variable:
- Purchased (0 = No, 1 = Yes)

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)

## Techniques Applied
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Scaling
- Train-Test Split
- Model Evaluation (Accuracy, Precision, Recall, F1-score)
- Cross Validation
- Hyperparameter Tuning
